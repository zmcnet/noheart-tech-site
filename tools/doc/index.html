快速入门#

无心工具箱是一款基于ADB和Fastboot协议的Android设备管理工具，提供图形化界面，无需记忆命令行即可完成刷机、分区管理、文件操作等任务。

💡 建议在使用前开启设备的 USB调试 和 OEM解锁 选项，路径为：设置 → 关于手机 → 连续点击版本号7次 → 开发者选项 → USB调试 / OEM解锁。

安装与配置#

无心工具箱为 Windows 平台应用，下载安装程序后运行即可完成安装。

  1. 前往 下载页面 获取最新版本安装程序
  2. 双击运行安装程序，按提示完成安装
  3. 安装完成后，从桌面或开始菜单启动 无心工具箱
  4. 首次运行时，Windows 可能弹出安全提示，点击「更多信息」→「仍要运行」
💡 工具箱支持双击.img 镜像文件自动刷入，安装后会自动关联文件格式。
⚠️ 安装时如遇杀毒软件拦截，请添加信任。工具箱不含任何恶意代码，拦截为误报。

首次连接设备#

连接设备前，请确保已完成以下准备工作：

  • 手机已开启 USB调试
  • 使用数据线连接电脑（部分线缆仅支持充电，请确认支持数据传输）
  • 手机弹出「允许USB调试」提示时，勾选「始终允许」并点击「确定」

连接成功后，工具箱将自动检测设备，仪表盘页面会实时显示设备信息。若设备未识别，可尝试：

  1. 点击 安装驱动 安装 Android USB 驱动
  2. 更换数据线或USB接口
  3. 在设备管理器中检查设备状态

设备仪表盘#

仪表盘是工具箱的首页，连接设备后自动读取并展示以下信息：

  • CPU核心利用率 / 实时频率 → 可视化展示各核心负载
  • 设备型号、Android版本、厂商
  • 序列号、CPU架构、SoC型号
  • 内存大小、存储空间 → 含已用/可用空间
  • 电池状态、网络类型、屏幕分辨率

所有数据实时刷新，无需手动操作。

分区管理#

分区管理分为 普通分区管理 和 动态分区管理 两个模块。

普通分区管理

适用于传统分区结构的设备，支持以下操作：

  • 刷写分区 → 将 .img 镜像文件写入指定分区
  • 擦除分区 → 清除指定分区的数据
  • 格式化数据 → 重置用户数据分区
  • 去除AVB2.0验证 → 解除Android Verified Boot校验
  • 切换槽位 → 在A/B双系统分区间切换
  • 去除FRP锁 → 绕过谷歌工厂重置保护
  • 解锁/上锁BL → 控制Bootloader的锁定状态

动态分区管理

专为搭载动态分区（Dynamic Partition）的设备设计，在普通分区功能基础上额外支持：

  • 调整逻辑分区大小 → 灵活分配super分区内的空间
  • 逻辑分区管理 → 创建、删除与配置逻辑分区
🔴 分区操作具有风险，错误的刷写或擦除可能导致设备无法启动。操作前请务必备份重要数据，并确认选择了正确的分区和镜像文件。

普通分区管理详情#

快速入门

本工具可以帮助您管理Android设备的分区，包括刷入镜像、擦除分区、解锁/上锁BL等功能。工具已内置fastboot功能，无需额外安装。

使用前请确保：

  • 设备已进入Fastboot模式
  • 使用质量好的数据线

基本操作流程：

  1. 将手机进入Fastboot模式（关机后按住音量减+电源键）
  2. 用数据线连接手机和电脑
  3. 点击【读取设备信息】获取设备信息
  4. 点击【读取分区列表】查看所有可用分区
  5. 根据需要选择要刷入、擦除或格式化的分区
  6. 点击对应按钮执行操作
💡 支持右键菜单直接刷入镜像文件，自动化程度高，操作更便捷！在 .img / .bin / .elf 文件上右键点击，选择【使用无心工具箱刷入】，或直接双击文件即可自动跳转刷入。

右键菜单自动刷入

核心亮点：

  • 智能分区识别 → 自动从文件名提取分区名（如 boot.img 识别为 boot 分区）
  • 自动设备检测 → 自动检测设备连接状态，无需手动操作
  • 智能分区匹配 → 支持直接匹配和A/B槽位智能匹配
  • 动态分区支持 → 自动识别动态分区设备，智能选择刷入策略
  • A/B槽位处理 → 自动判断是否需要刷入A/B两个槽位
  • 单例模式 → 确保只有一个程序实例运行，避免冲突

智能识别机制：

  • 直接匹配：boot.img → boot 分区
  • A/B槽位匹配：boot.img → boot_a 分区（当前槽位）
  • 支持格式：.img、.bin、.elf
  • 大小写不敏感：BOOT.img → boot 分区
  • 下划线支持：system_ext.img → system_ext 分区

A/B槽位智能处理：

  • 动态分区设备：如果匹配到A/B槽位分区，自动勾选【刷入AB】；super 和 cust 分区特殊处理，只刷入当前槽位
  • 非动态分区设备：直接刷入匹配的分区，不涉及A/B槽位处理

如果自动识别失败，程序会提供回退方案：显示分区选择对话框，用户可以手动选择目标分区。

基础概念

什么是Fastboot模式？
Fastboot是Android设备的特殊模式，用于刷机操作。

  • 进入方法：手机关机后，同时按住【音量减键】和【电源键】不放，直到进入Fastboot界面
  • 退出方法：按住电源键10秒以上，或使用 fastboot reboot 命令重启

什么是分区？
Android系统将存储空间划分为多个区域，每个区域称为分区。

  • 动态分区设备：有 super 分区作为容器，system、vendor、product 等作为逻辑分区在 super 内部，可以动态调整分区大小，需要使用Fastbootd模式操作
  • 非动态分区设备：没有 super 分区，boot、system、vendor 等都是独立的物理分区，分区大小固定，直接在Fastboot模式操作

常见分区：

  • boot：启动分区，包含内核和启动文件
  • system：系统分区，包含Android系统文件（非动态分区）
  • vendor：厂商分区，包含厂商定制的驱动和配置（非动态分区）
  • super：超级分区，包含多个逻辑分区（动态分区）
  • userdata：数据分区，存储用户数据和应用数据
  • recovery：恢复分区，包含恢复模式程序

什么是BL锁？
BL锁（Bootloader锁）是厂商设置的安全机制。锁定状态下无法刷入非官方系统，解锁后可以刷入第三方系统、获取Root权限等。解锁BL锁会清除所有数据，解锁后部分银行应用可能无法使用。

什么是FRP锁？
FRP（Factory Reset Protection）是谷歌的账号锁机制。当设备恢复出厂设置后，需要输入之前登录的谷歌账号才能使用。去除FRP锁可以绕过这个验证，重新激活设备。仅用于恢复自己设备的所有权，请勿用于非法用途。

什么是AVB校验？
AVB（Android Verified Boot）是Android的启动验证机制。开启AVB时，系统会验证每个分区的完整性，如果分区被修改则无法启动。去除AVB校验后可以刷入修改过的系统镜像，但会降低系统安全性。

什么是A/B分区？
现代Android设备采用A/B分区机制，每个分区都有两个副本（A槽和B槽）。系统更新时在非活动槽位安装更新，更新成功后切换到新槽位，如果更新失败可以回退到旧槽位。

设备连接

  1. 将手机关机
  2. 同时按住【音量减键】和【电源键】不放
  3. 直到屏幕显示Fastboot界面（通常是机器人或文字）
  4. 用数据线连接手机和电脑
  5. 点击【读取设备信息】确认连接成功
⚠️ 使用原装或质量好的数据线，劣质数据线可能导致连接不稳定。操作过程中请勿断开数据线，确保设备电量充足（建议50%以上）。

动态分区管理详情#

动态分区（Dynamic Partitions）是Android 10引入的新型分区管理机制。与传统分区不同，动态分区将所有分区（system、vendor、product等）合并为一个大的分区 super 分区内，可以灵活调整各分区大小，无需重新分区。

基本概念

  • super 分区：容器分区，包含所有逻辑分区
  • 逻辑分区：system、vendor、product、odm等，全部在super内部
  • group：一组逻辑分区，共享空间配额

如何使用动态分区模式

  1. 进入Fastbootd模式（动态分区设备）或Fastboot模式
  2. 在分区管理中选择【动态分区】标签页
  3. 查看当前逻辑分区布局和大小
  4. 根据需要调整、创建或删除逻辑分区
  5. 刷入修改后的镜像

调整分区大小

  1. 在动态分区界面选择要调整大小的逻辑分区
  2. 点击【调整大小】按钮，打开大小调整对话框
  3. 输入新的分区大小（支持MB/GB单位）
  4. 点击【确定】确认操作
⚠️ 调整分区大小可能导致数据丢失，请提前备份重要数据。逻辑分区大小之和不能超过super分区总大小。

创建逻辑分区

  1. 在动态分区界面点击【新建分区】
  2. 输入分区名称、大小和所属group
  3. 点击【确定】创建分区

删除逻辑分区

  1. 选择要删除的逻辑分区
  2. 点击【删除】按钮
  3. 在确认对话框中点击【确定】
🔴 删除分区将导致分区内所有数据丢失，请谨慎操作。

重启管理#

重启管理功能允许您在不使用物理按键或ADB命令的情况下，快速在不同设备模式间切换。

  • 重启到系统 → 正常的Android系统
  • 重启到 Recovery → 恢复模式，用于刷机、备份等
  • 重启到 Fastboot → Bootloader模式，用于分区操作
  • 重启到 Fastbootd → Fastbootd模式，用于动态分区操作
  • 关机 → 关闭设备
  • 重启到 EDL → 紧急下载模式（高通设备）
  • 重启到 BROM → BROM模式（联发科设备）
💡 重启到EDL或BROM模式需要安装对应驱动，这些模式通常用于深度维修或救砖刷机。

文件管理#

文件管理功能允许您浏览、上传、下载和删除设备上的文件，支持常用文件操作。

  • 设备文件浏览器 → 浏览设备上的文件目录
  • 上传文件 → 将电脑文件上传到设备
  • 下载文件 → 将设备文件下载到电脑
  • 删除文件 → 删除文件或文件夹
  • 新建文件夹 → 创建新文件夹
  • 复制/移动 → 复制或移动文件
  • 批量操作 → 多选文件进行批量处理
💡 Root设备可访问更多系统目录（如/data、/system），非Root设备仅能访问存储目录。

扩展 / 模块管理#

工具箱提供模块管理功能，用户可以通过安装第三方模块来扩展功能。

安装模块

  1. 下载模块安装包（.wxp或.zip文件）
  2. 打开【扩展管理】→ 点击【安装模块】
  3. 选择下载的模块文件
  4. 等待安装完成
  5. 重启工具箱以加载新模块

可用模块

  • Payload解包器 → 解析OTA升级包，提取分区镜像
  • SELinux策略合并器 → 合并和编辑SELinux策略文件
  • Boot镜像工具 → 解析和编辑boot镜像头
  • 框架工具 → 分析APK文件、smali编辑
  • 更多模块 → 关注官方模块商店获取更新

模块设置

  • 启用/禁用模块：在模块列表右侧切换开关
  • 模块更新：在扩展管理器中点击【检查更新】
  • 模块卸载：右键模块 → 【卸载】
⚠️ 请从官方或可信渠道下载模块，避免安全风险。

命令行#

工具箱内置命令行工具，无需额外安装即可直接执行ADB和Fastboot命令。

  • ADB Shell → 在设备上执行shell命令
  • Fastboot命令 → 执行Fastboot命令
  • 命令历史 → 查看之前执行的命令
  • 脚本执行 → 批量执行ADB/Fastboot命令

常用命令示例

  • adb devices → 列出已连接设备
  • adb shell reboot recovery → 重启设备到recovery
  • adb install app.apk → 安装APK文件
  • adb pull /sdcard/file.txt → 从设备下载文件
  • fastboot flash boot boot.img → 刷写boot分区

Payload 解包器#

Payload解包器是一款用于解析Android OTA升级包、提取分区镜像的内置工具，方便ROM研究与开发。

主要功能

  • 解析 payload.bin → 读取OTA包中的分区信息
  • 提取分区镜像 → 提取指定分区镜像
  • 批量提取 → 一次性提取所有分区镜像
  • 支持多版本 → 支持Android 10-14的OTA包

使用步骤

  1. 打开【Payload解包器】模块
  2. 点击【选择OTA包】选择OTA zip文件
  3. 工具自动解析payload.bin并显示分区列表
  4. 选择需要提取的分区
  5. 点击【提取】将镜像保存到输出目录
💡 加密的OTA包不支持直接解包，请先解密或使用官方解包工具。

SELinux 策略合并器#

SELinux策略合并器是一款用于分析和合并SELinux策略文件的工具，帮助开发者理解和修改Android安全策略。

主要功能

  • 策略分析 → 解析SELinux策略文件，展示类型、规则信息
  • 规则合并 → 合并多个策略文件中的规则变更
  • 差异对比 → 对比两个策略文件的差异
  • 规则查询 → 搜索特定类型或权限规则

使用场景

  • 分析自定义ROM的安全策略
  • 检查Root/Magisk修改后的权限变化
  • 调试SELinux权限拒绝问题

常见问题#

设备无法识别？

请检查：1）已开启USB调试；2）使用原装数据线；3）安装ADB驱动；4）尝试更换USB接口。

如何进入Fastboot模式？

将手机关机后，同时按住音量减键+电源键不放，直到进入Fastboot界面。部分机型需要按住音量减键的同时插入数据线。

如何退出Fastboot模式？

长按电源键10秒以上强制重启，或使用工具箱的重启管理功能重启到系统。

刷机是否会清除数据？

刷写不同分区影响不同：刷写boot、system等分区一般不会清除用户数据；擦除userdata或格式化数据分区一定会清空所有数据。操作前请务必备份重要数据。

如何解锁BL？

先在官网申请解锁码，然后在Fastboot模式下连接设备，在分区管理中点击【解锁BL】，输入解锁码即可完成。注意：解锁BL会清空所有数据，部分银行和支付类应用可能无法使用。

如何获取Root权限？

先解锁BL，然后刷入第三方Recovery（如TWRP），最后在Recovery中刷入Magisk或SuperSU即可获取Root权限。工具箱提供了刷入Recovery等镜像的功能。

连接后为什么看不到存储？

Android 11之后加强了分区存储限制，文件访问受到限制。请使用工具箱的文件管理功能操作，或通过ADB命令行访问。Root设备可绕过限制。

动态分区设备如何刷机？

动态分区设备请先启动到Fastbootd模式，然后在动态分区管理中选择要刷入的逻辑分区。也可以使用【一键全刷】功能一次性刷入所有分区。

如何刷入OTA升级包？

方式一：使用Payload解包器提取分区镜像，再逐一刷入；方式二：使用工具箱的【刷入OTA】功能直接刷入OTA zip包（支持动态分区设备）。
